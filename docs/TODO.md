## Улучшения

- [ ] Широкий экран 16:9 (пакет 3 из обзора идей).
  - Проекция `FUN_100075D0` в `_d3d.dll`: `fx = W·zoom·0.05`, `fy = H·zoom/15`, то есть 4:3 зашито. Нужны две правки: 0x1000768B и 0x100076AB.
  - Режимы 16:9 в `ddraw.dll` и в фильтре окна выбора разрешения.
  - Маски видимости земли покрывают 16:9 с запасом около 5°, 21:9 уже нет. Проверять поворотами камеры.
- [ ] Угол обзора шире: имеет смысл только вместе с 16:9.
- [ ] Дальность тумана как опция в `hogs.ini`. Откроется край карты.
- [ ] Патчер при обновлении дописывает в старый `hogs.ini` только секцию `[Render]`. Для `Borderless`, `[Startup]` и `[Gamepad]` пока работают значения по умолчанию в коде. Дописывать все недостающие секции и ключи.
- [ ] Решить, поднимать ли при запуске громкость игры в микшере Windows, если там застрял 0 от старой версии. Сейчас в README только совет.

## Не стоит (по обзору идей)

- Обзор и прицел мышью: игра читает ввод 25 раз в секунду и поворачивает не больше чем на 5,5° за такт, это ощущается как стик.
- Клики мышью по меню: в игре нет кода, который понимает, куда нажали.
- MSAA, анизотропная фильтрация, HD-текстуры: игра склеивает текстуры в общие листы на лету, отдача маленькая.
- Бой плавнее 25 кадров в секунду: только достраиванием промежуточных кадров, большая работа.
